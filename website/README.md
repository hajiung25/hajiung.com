# hajiung.com

TanStack Start 기반 한국어 경력·포트폴리오. 현재 로컬 미리보기 단계입니다.

```sh
pnpm install
pnpm dev
# http://localhost:3000
pnpm build
pnpm typecheck
```

콘텐츠는 `src/content/career.ts`, 화면은 `src/components/Portfolio.tsx`, 디자인과 인쇄 스타일은 `src/styles.css`에서 수정합니다. 소개 문구는 Portfolio.tsx에 있습니다.

Cloudflare 도메인 연결과 배포는 아직 하지 않았습니다. 기존 PDF의 2025년 예상 실적과 측정 기준이 없는 수치는 웹 콘텐츠에 포함하지 않았습니다.

공식 구성 참고: https://tanstack.com/start/latest/docs/framework/react/build-from-scratch
