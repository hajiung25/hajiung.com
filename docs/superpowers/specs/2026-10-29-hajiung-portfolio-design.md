# hajiung.com 개인 경력·포트폴리오 사이트

## 목적과 승인된 방향

깔끔한 이력서처럼 한 페이지를 스크롤하며 소개, 프로젝트, 경력을 읽는 한국어 개인 사이트. 개발 기술 자체보다 문제를 이해하고 설계·구현·운영으로 풀어온 과정이 드러나게 한다. 별도의 프로젝트 상세 페이지 대신 본문에서 내용을 충분히 읽는다.

## 화면 구성

1. 상단: 하지웅 / 개발자, GitHub 링크, 섹션 이동 목차.
2. 소개: ‘함께 나눈 고민을 실제 변화로 이어가는 개발자’와 현재 합의된 My Career 문구. 화면 전체를 차지하는 홍보형 히어로 대신 문서형 머리말.
3. 경력 및 프로젝트: 청담네트웍스 → 케어나인 → 비엔시스템 순서로 회사·재직 기간·역할을 표시하고 관련 프로젝트를 아래에 배치. 회사 경력과 프로젝트를 별도 섹션에서 반복하지 않는다.
4. 기타 경험: 대량문자 전송자격인증제 프로젝트와 개발 전 시설관리 경력은 주 경력보다 낮은 비중으로 구분한다.
5. 기술 및 교육: 선별한 기술과 코드스테이츠 교육을 간결하게 표시.
6. 하단: GitHub, 원본 경력기술서 링크, 인쇄 버튼. 공개 이메일은 확인된 주소가 마련될 때 추가한다.

## 콘텐츠 기준

- 최신 경력은 이 대화에서 검토한 이력서와 GitHub·Linear 근거를 사용한다.
- 이전 경력은 Google Drive의 하지웅_경력기술서.pdf를 참고한다. 원본: https://drive.google.com/file/d/1oszR-4kppU2J5-XLho-20NHK9nUKT6Vg/view
- 문서는 2025년 3월 자료다. 과거 회사의 ‘진행 중’과 예상 실적은 현재 실적으로 옮기지 않는다. 케어나인 표기는 최근 정리한 이력서에 맞춘다.
- 프로젝트별로 짧은 소개, 문제·접근·변화가 드러나는 2~4개 항목, 핵심 기술을 표시한다. 기능 목록이나 모든 프로젝트의 똑같은 소제목 반복을 피한다.
- 원문 수치의 측정 기준이 없는 경우 첫 버전에서는 정성적 변화로 기술한다. 새 수치나 개인 단독 기여를 만들어내지 않는다.
- 우주몰, 시세임당·모두의시세, 라이브커머스 자동응답, 케어나인 앱·운영 시스템, 심리테스트 및 재고 관리 프로젝트를 중심으로 구성한다.

## 시각 디자인과 동작

- 밝은 배경, 짙은 회색 글자, 얇은 구분선, 절제된 포인트 색상 하나.
- 읽기 좋은 본문 폭과 한글 줄바꿈, 넉넉한 행간. 데스크톱은 날짜·회사 정보와 본문을 정렬하고 모바일에서는 한 열로 전환.
- 카드 격자, 기술 숙련도 막대, 과한 등장 애니메이션 없이 문서의 정보 위계로 구분.
- 앵커 목차, 키보드 포커스, 충분한 대비, reduced-motion 지원.
- 인쇄 CSS로 내비게이션·버튼을 제외하고 경력기술서를 PDF로 저장할 수 있게 한다.
- 실제 이미지가 확보되지 않은 프로젝트는 가짜 제품 화면을 만들지 않고 텍스트로 표현한다.

## 기술 구조

- TanStack Start + React + TypeScript + Tailwind CSS, pnpm.
- Cloudflare Workers 배포를 목표로 구성. hajiung.com은 Cloudflare에서 구매한 도메인이다. 실제 계정 및 DNS 연결은 배포 단계에서 확인한다.
- 경력 데이터는 타입이 있는 로컬 콘텐츠 파일, 화면은 소개·경력·프로젝트·기술·푸터 컴포넌트로 분리.
- 데이터베이스, 인증, CMS, 별도 API 없이 시작. TanStack Query·Zustand는 필요한 상태나 데이터 요청이 생길 때 도입.
- SSR로 본문 제공. 제목·설명·canonical·Open Graph·robots·sitemap 설정.
- 없는 경로는 명확한 404 화면 제공. 외부 링크는 확인된 URL만 사용.

## 검증과 배포

- 타입 검사와 프로덕션 빌드.
- 브라우저에서 모바일·데스크톱 레이아웃, 앵커 이동, 외부 링크, 인쇄 스타일, 콘솔 오류 확인.
- 먼저 로컬에서 실제 화면을 검토할 수 있게 제공하고, 배포 후 도메인의 HTTPS·본문·메타데이터를 확인한다.
- 공개 사이트에 이력서 편집 화면 스크린샷, 집 주소, 전화번호, 비공개 저장소의 소스·내부 링크를 포함하지 않는다.
